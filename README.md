# Ứng dụng Xác thực Chứng chỉ & Văn bằng bằng Blockchain

## 📌 Giới thiệu

Ứng dụng này giúp các tổ chức giáo dục phát hành và xác thực chứng chỉ/văn bằng một cách **an toàn, minh bạch và không thể làm giả** nhờ công nghệ **Blockchain**.  
Người dùng, nhà tuyển dụng hoặc các bên liên quan có thể nhanh chóng kiểm chứng thông tin chỉ bằng một cú click hoặc quét QR Code.

## ✨ Tính năng chính

- 🏫 **Phát hành chứng chỉ/văn bằng** từ tổ chức đã được xác thực.
- 🔐 **Bảo mật & chống giả mạo** bằng cách mã hóa dữ liệu và lưu hash trên blockchain.
- 📜 **Xác thực chứng chỉ** thông qua mã định danh duy nhất hoặc QR Code.
- 🔎 **Tra cứu công khai** thông tin cơ bản của chứng chỉ (không tiết lộ dữ liệu nhạy cảm).
- 📲 **Hỗ trợ đa nền tảng**: Web App và Mobile App.

## 🛠️ Công nghệ sử dụng

- **Frontend**: ReactJS / Next.js (Web), React Native (Mobile).
- **Backend**: Node.js (NestJS/Express).
- **Blockchain**: Ethereum / Polygon (EVM-based) hoặc Hyperledger Fabric.
- **Database**: PostgreSQL / MongoDB (lưu metadata).
- **Storage**: IPFS / Filecoin (lưu trữ file PDF, hình ảnh chứng chỉ).
